# Private forum interaction trial

The existing Norwegian and English `/for-oss-alle-preview/` pages include two
rooms with fictional conversations. The room descriptions explain why people in
or formerly in prison and relatives have separate spaces. The existing portal
continues to explain the distinction between creative collaboration and the
editorial/activist section.

Visitors can open a sample conversation, switch rooms or threads, write an
invented reply, keep a draft in the current tab, clear it and return to the
overview. Drafts are held only in a JavaScript Map. They do not use browser
storage, accounts, cookies, a backend or network requests. Reloading the page
clears them. Draft text is never added to the sample conversation as a real post.
The interface explicitly asks visitors not to enter personal or case information.

This is a private synthetic interaction trial, not an open forum, confidential
support service, verified membership system or evidence of moderation. Production
identity, access controls, privacy and moderation remain separate prerequisites.
Without JavaScript the room descriptions remain readable and controls stay
disabled. Keyboard focus moves to the conversation heading when it opens and
returns to its opener when the overview is restored.
