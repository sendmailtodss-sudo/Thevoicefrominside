# BytePlus Seedance 2.5 integration for Codex
This is an opt-in command-line integration for the existing website repository. It is not linked to Dreamina Advanced subscription credits. BytePlus ModelArk has separate API billing.

## Supported operations
- Prepare a task locally (free, does not contact BytePlus)
- Submit a video generation task (paid; explicit confirmation required)
- Check task status
- Download a successful task to a local MP4

## Setup in Codex Cloud
1. In BytePlus ModelArk activate Dreamina Seedance 2.5, obtain an API key from the official console.
2. Save it as a **secret** named `ARK_API_KEY` in the Codex environment. Never paste it into chat, repository files or logs.
3. Allow outbound API access to `ark.ap-southeast.bytepluses.com`. Downloading output videos may need access to the signed video-host domain returned by the API.
4. In this repository, run `npm test` and `node scripts/seedance.mjs prepare --prompt "A cinematic, fictional prison corridor" --seconds 5`.
5. Only after checking BytePlus pricing and confirming spending, submit:
```sh
node scripts/seedance.mjs submit --prompt "Cinematic fictional prison corridor, photorealistic, respectful, no logos" --seconds 5 --confirm-paid
node scripts/seedance.mjs status --id TASK_ID
node scripts/seedance.mjs download --id TASK_ID --output media/seedance/scene-01.mp4
```
6. Review and optimize output video (codec, poster, reduced motion, mobile sizing) before integrating into the site. Save output to permanent storage; BytePlus links expire.

## Safeguards
- NO video is generated by default. Only `submit --confirm-paid` sends a paid generation request.
- The CLI uses only Node built-ins and supports offline tests and preview.
- Task IDs and temporary links are not API credentials, but avoid publishing them unnecessarily.
- Keep generated fictional reenactments clearly labeled; do not imply footage is authentic.
- BytePlus docs state Seedance 2.5 does not support directly uploading references containing real human faces without the applicable authorized portrait flow.
- This is an API client for Codex, not a deployed MCP server or a ChatGPT plugin.
