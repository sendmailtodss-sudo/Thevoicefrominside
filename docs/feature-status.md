# Development feature status

This is a public code export from website v34, not a new website release.

| Area | Contributor preview | Production activation |
| --- | --- | --- |
| Navigation and reading layouts | Local HTML, example editorial text | Separately managed website |
| Gallery and individual artwork routes | Stable IDs, example images, zoom and navigation | Original artwork rights handled separately |
| Clothing previews | Local design calculations and preview UI | Checkout and payments disabled |
| Workshop, document organisation and draft helpers | Local UI/code and synthetic tests | Never submit real case files to a development instance |
| Search | Route titles and example content | Production index excluded |
| Accounts, submissions and collaboration messages | UI/code only; local API disabled | Requires separate authentication, moderation and storage setup |
| Original-art sales, bids and legal fund | Code under review | No transactions, bank connection or commitments activated |
| OCR/model adapters | Code and synthetic tests | External providers not configured by this repo |
| Languages | Norwegian/English UI; partial Chinese/Cantonese UI dictionaries | Translation review and fallback remain necessary |

All contributors are welcome; no prison or family connection is required. Features and test success are not claims that a public service is operating.
