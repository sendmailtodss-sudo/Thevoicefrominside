# Visual Grill review

Read `../cinematic-production/SKILL.md` and this skill's [source workflow](references/grill-me.md). Follow the project adaptations below where the generic source differs. This is instruction-only; it supplies no browser, display, renderer or paid service.

## Enter at the right phase

The current user requires research, reviewed/activated skills, and a fresh reading of the original vision and available source attachments before this interview. Do not ask creative questions during a research/setup-only task. Record inaccessible material without pretending to have read or seen it. Keep private evidence outside the public repository.

## Show, then ask

1. Reconcile accepted decisions and unresolved choices from the actual brief. Build a decision tree; only questions whose prerequisites are already settled belong to the current frontier. Preserve the user's selected decisions. Recommendations are not approvals or preselected answers.
2. Research facts independently: tools, runtime, source content, rights, costs and technical feasibility are the agent's work. Do not ask the user to choose technical internals or repeat facts available in the environment.
3. Prepare concrete examples for each visual choice using existing authorized material and permitted research. Identify the visible difference and consequence. Use working supported previews or stable private review links, and verify that the user can access the examples before asking the question. An internal viewing tool, invisible attachment, link dump or promised future example is insufficient. Do not publish private media merely to repair display.
4. Ask at most three independent questions in one frontier round, in the user's language. Each question should identify its visible examples, give a reasoned recommendation and allow the user to select or revise the creative direction. Hold dependent questions for a later round.
5. Incorporate answers, update the tree, and show any new examples needed by the next frontier. Summarize accepted decisions, genuinely open issues and explicit exclusions when the frontier is settled.

Creative alignment is required by this user's task order. Do not invent a second generic “Aligned? May I start?” gate when the actual answers and existing mandate already supply it. Record the evidence and continue within authorized scope. Do not implement while a material required creative decision remains unresolved. A paid-production hold remains active until explicitly released within scope.
