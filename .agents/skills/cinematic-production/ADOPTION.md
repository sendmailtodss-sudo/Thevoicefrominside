# Project adaptations and activation

This is the project-owned entry point. It organizes specialist instructions
without silently changing the user's creative decisions or service permissions.

- Preserve the actual ordered brief. Generic advice to use five to seven beats
  or four to eight chapters does not authorize deleting requested scenes.
- The existing photographic journey and gallery make renderer selection a
  measured per-segment decision. This package chooses no replacement renderer
  and installs no Three.js, GSAP, Remotion, Blender or After Effects runtime.
- The main journey forbids ambient movement, delayed scrubbing, damping and
  pointer-driven camera motion. Analytic progress and fixed seeds take priority.
- Third-party generator commands and model IDs are examples from another
  environment. Use the connected Higgsfield tool's current schema and actual
  account, not another provider, a copied shell script or an invented parameter.
- Published model, price, duration and version claims must be rechecked. A
  reference workflow's budgets and standard clip length are not this project's
  budget or an instruction to consume the current balance.
- The user's current spending hold remains in force. Installing or reading a
  skill does not lift it. Resume only within the latest direct authorization
  after the disputed creative direction has actually been resolved.
- Keep original artwork exact where the brief requires it; a generative
  approximation is a draft. Treat display rights and product reproduction
  rights separately.
- Reference demos and executable templates are not part of this instruction
  installation. Read `SOURCE.json` and each specialist's adoption note for
  included material, provenance and omitted dependencies.

The source inventory in [SOURCES.md](SOURCES.md) distinguishes installed text
from read-only external references. No publication or runtime behavior changes
are implied by installing this package.
