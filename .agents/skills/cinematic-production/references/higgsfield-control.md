# Higgsfield production control

## Capability discovery

The connected tool schema is authoritative. Read the official Higgsfield router
skill and resolve a named command before invoking it. Browse current models and
inspect the chosen model's parameters, reference roles, durations, aspect ratios
and edit support. Do not copy model names, example prices or tool calls from a
third-party skill into a submission.

The official Cinema Studio, shot-list, camera-control and VFX guides in
`../SOURCES.md` provide direction methods. A web feature does not establish an
equivalent MCP tool, an installed local application or access to downloadable
passes. Verify each capability in the actual working interface.

## Preparation

Use the reconciled brief and visual bible. Define a shot's purpose, action,
blocking, optics, camera path and speed, light, materials, incoming/outgoing
state and immutable continuity references. Keep invariant direction separate
from the parameter intentionally being varied.

Prefer one controllable action and camera move per continuity segment. Use
multi-shot only when the selected tool actually supports an ordered shot list
and that edit fits the user's experience. Long compound prompts are not a
substitute for a planned shot sequence.

Use inspected frames, not asset filenames or a contact sheet alone, to anchor
start/end continuity. Verify reference upload identity and placement. A
destination still must already contain the correct art, wardrobe and spatial
composition if the model cannot enforce those elements independently.

## Paid operation

Check for an active production hold first. If held, stop before quoting,
uploading for a job, registering a paid session or generating. Research and a
skill installation do not authorize production.

When production is authorized, reconcile actual account balance, the official
quote for the full inputs, remaining authorized allocation and protected
reserve. One owner reserves one stable submission ID before submitting. Run
jobs sequentially. A catalog recommendation or quote is not a completed job.
For an uncertain result, query that same ID; do not create a duplicate attempt.

Save actual receipts and raw outputs privately. Confirm terminal state, inspect
the complete clip and sampled frames, and compare it to concrete visual
acceptance criteria. Separate technical completion from creative acceptance.
Diagnose rejected output before proposing a different attempt. Do not
automatically retry, upgrade, extend or regenerate to spend an available budget.

## Compositing and editor boundaries

Preserving a real source plate, camera, identity, lighting and performance is a
different task from generating a fresh scene. Use a supported video-edit path
when that is the actual task. Never assume an image-to-video model preserves
the source motion or exports separate layers.

Higgsfield documents editing and depth features in its web product. The current
tool/account must still prove access, formats, resolution and whether camera,
depth or masks can be exported. A finished beauty video alone supplies no
verified 3D geometry or calibrated camera. Literal multilingual text and
original artwork require their own fidelity checks.

`/use-blender` and `/use-after-effects` describe local application integrations.
Loading those instructions does not connect a desktop, install licensed software
or make their tools available in a cloud chat. Resolve the official setup path
and report actual availability before proposing one of these as the renderer.

## Showing results

Use the tool's supported preview for the exact existing result when the user
requests review. Do not generate or import another copy just to display it.
Never pass a job UUID into a field requiring an owned media UUID. Provide a
verified stable private view/download link if the chat's preview is not visible.
